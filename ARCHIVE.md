# 📦 Archived / 已归档

[English](#english) · [中文](#中文)

---

## English

This repository has been **archived**. The current release is the **final version** — there will be no further updates, bug fixes, or support, and issues/PRs will no longer be monitored.

### Why archive?

The patching engine has reached a stable, feature-complete state. It now works reliably across **multiple vendors and multiple ABL versions**, and the core patching logic has not changed in a long time. In other words, the project has done exactly what it set out to do — there is simply nothing meaningful left to maintain or add.

### What this means

- **No more maintenance.** No new features, no bug fixes, no support requests. Issues and pull requests will be closed without review.
- **The code still works.** Being archived does *not* mean broken — it means *finished*. The current toolkits, module, and build targets all continue to function as documented.
- **Forks welcome.** If you want to keep this moving forward or fix something for your own device — please **fork the repository** and maintain your own version. You do not need my permission; the GPL license already permits it.

### For fork maintainers

- The [README](README.md) and [Wiki](https://github.com/superturtlee/gbl_root_canoe/wiki) still document everything needed to build and use the toolkits.
- See [Contributors.md](Contributors.md) for the history of who built what.
- If you publish a maintained fork, consider linking back here so users can find you.

Thank you to every contributor, tester, and community member who helped make this project what it is.

## 中文

本仓库已**归档**。当前版本为**最终版本**——不再有任何更新、错误修复或技术支持，Issues 和 PR 也将不再处理。

### 为什么要归档？

补丁引擎已经达到了稳定、功能完备的状态。它如今在**多个厂商、多个 ABL 版本**上都能可靠工作，且核心补丁逻辑已经很久没有变动。换言之，这个项目已经完成了它的使命——实在没有更多需要维护或新增的内容了。

### 这意味着什么

- **不再维护。** 没有新功能、没有错误修复、不接受支持请求。Issues 和 Pull Request 将直接关闭，不再审查。
- **代码仍然可用。** 归档**不代表**损坏——而是代表**完成**。当前的工具包、模块和各构建目标均仍按文档所述正常工作。
- **欢迎 Fork。** 如果你想继续推进这个项目——适配新芯片、增加新厂商，或为自己的设备修一些东西——请**自行 Fork 仓库**并维护你自己的版本。无需征得我的同意，GPL 许可证已经允许你这样做。

### 致 Fork 维护者

- [README](README_zh.md) 和 [Wiki](https://github.com/superturtlee/gbl_root_canoe/wiki) 仍然记录了构建和使用工具包所需的全部信息。

感谢每一位贡献者、测试者和社区成员，是你们让这个项目走到了今天。
